总结当前对话，写一份交接文档，以便新的 AI Agent 接手继续工作。

接手的新 Agent 看不到本次对话的任何历史，这份文档是它唯一的上下文，必须自足。

文档放在 `.pi/handoffs/` 目录下，命名 `HANDOFF-<主题>.md`，主题由你概括。同名文件已存在就更新它，不要新建第二个文件。

交接文档按这个结构写：

## 目标
这次工作要达成什么。

## 当前状态
已经完成了什么、进行到哪一步。

## 关键决策与原因
做过哪些选择、为什么这么选，有没有被否掉的方案。

## 下一步
接着要做什么，按优先级排。

## 注意事项
坑、约束、还没解决的问题。

## 建议使用的 skill
接手者可以调用哪些 skill，分别用在什么场景。

不要在文档里重复其他地方已有的内容 —— 规格、计划、ADR、issue、commit、diff 一律用路径或 URL 引用。

不要写入敏感信息，比如 API 密钥、密码、个人身份认证信息。

用户传递的参数是下一步工作的重点，据此调整文档。
